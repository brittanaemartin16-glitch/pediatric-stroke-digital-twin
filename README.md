# Pediatric Stroke Digital Twin

This is a synthetic research-communication prototype for Team 7's pediatric stroke project. It demonstrates how clinical, imaging, EEG, genetic, and treatment inputs could update a fictional child's post-stroke epilepsy research estimate and its explanation.

## Publish it on Streamlit Community Cloud

1. Create a new public GitHub repository.
2. Upload `app.py`, `requirements.txt`, and `patient-digital-twin.png` to the repository's main folder.
3. Go to https://share.streamlit.io and sign in with GitHub.
4. Select **Create app**, choose the repository, and set the main file to `app.py`.
5. Choose an available app name and deploy it.

The public address will end in `.streamlit.app`. All patient values and scoring in this prototype are fictional and illustrative.
